      GENERAZIONE AUTOMATICA
      Collegamento AI
      
            ✦
          
      
          
      L’app usa l’API OpenAI con la tua chiave. L’uso può comportare costi sul tuo account API. Dopo il consenso, vengono inviati al provider il testo dell’annuncio, il testo estratto dal CV, il contesto candidato e le istruzioni degli agenti attivi. Nessuna candidatura viene inviata.
      
          
      La ricerca web usa OpenAI web_search. Modello agenti predefinito: GPT‑5.6 Luna. Tariffe API per milione di token: Luna $0,20 input / $1,20 output; GPT‑4.1 nano $0,10 / $0,40. Cache e Laya riducono il numero di chiamate, ma Luna costa di più per token.
      
          
      La dashboard conta localmente chiamate e token utilizzati. Per gli addebiti effettivi consulta la pagina utilizzo OpenAI.
      
          
      Controllo la configurazione AI…
